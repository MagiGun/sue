What it is

Every tool in Sue works on the same project, so a picture, a page and a sound are the same things wherever you use them. Nothing is copied or converted between apps.

Sue Paint

Pressure-sensitive brushes, layers, vector lines, screen tones, filters and rulers, with comics, webtoons and frame-by-frame animation, laid out the way Clip Studio Paint users expect.

Sue Writer

Write documents, novels, scripts and papers, then publish them as PDF, Word, EPUB and more.

One canvas

Every file of your project side by side on an endless surface, with a file manager, a player and a converter close at hand.

Yours, offline

No account and no cloud. Sue opens PNG, JPEG, JPEG XL, Photoshop and many more files, and its AI tools run on your own machine.

Installing on Windows

The -setup.exe is the easiest. Sue isn't code-signed yet, so Windows may say "Windows protected your PC" or "Unknown publisher": choose More info, then Run anyway. Before extracting the portable zip, right-click it, choose Properties and tick Unblock, or Windows asks again for every program inside.

Or install with Scoop, which skips the warning and keeps Sue up to date with scoop update sue:

scoop install https://github.com/MagiGun/sue/releases/latest/download/sue.json
