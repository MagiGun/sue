# Sue Paint terminology glossary

Use these terms consistently in Sue Paint translations. English is the source
term. French and German terms follow the official CLIP STUDIO PAINT manuals
where there is a matching command or interface term. A term marked **(Sue)**
names a Sue feature with no exact CLIP STUDIO PAINT equivalent. Keep product
names and keyboard shortcuts unchanged.
